# Recursion

This project is part of the JavaScript course from **The Odin Project**. In this project, I implemented iterative and recursive solutions to the Fibonacci sequence and developed a recursive merge sort algorithm to explore recursion and the divide-and-conquer approach.

By completing this project, I demonstrated an understanding of recursive functions, base cases, recursive calls, array manipulation, and sorting algorithms. I also strengthened my ability to break complex problems into smaller subproblems and understand how recursive algorithms work.

This project marked an important step in developing my computer science fundamentals and deepening my understanding of recursion, algorithm design, and problem-solving in JavaScript.
